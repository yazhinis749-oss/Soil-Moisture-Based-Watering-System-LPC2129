# Soil Moisture-Based Automatic Watering System with GSM Alert Using LPC2129

## Project Overview
This project is an automatic soil moisture-based watering system developed using the LPC2129 microcontroller. It monitors soil moisture levels and automatically controls a water pump. GSM technology is used to send SMS notifications about the soil condition and watering status.

## Hardware Components
- LPC2129 Microcontroller
- Soil Moisture Sensor
- GSM Module
- LCD Display
- DC Water Pump
- Relay Module
- Green LED
- Red LED
  
## Software Requirements
- Embedded C
- Keil µVision IDE
- LPC2129 Microcontroller

## Working Principle
1. The soil moisture sensor continuously monitors the soil condition.
2. When the soil becomes dry, the LPC2129 activates the water pump.
3. When the soil becomes wet, the water pump automatically turns OFF.
4. The GSM module sends SMS notifications about the soil condition.
5. The LCD displays the current soil and watering status.

## Key Features
- Automatic soil moisture monitoring
- Automatic water pump control
- GSM-based SMS alerts
- LCD status display
- Microcontroller-based automation
